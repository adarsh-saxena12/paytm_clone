# 💸 Paytm Clone

A full-stack **digital wallet application** inspired by Paytm, built with **React.js, TypeScript, Express.js, MongoDB, and Redis**. This project simulates real-world payment flows with features like UPI transactions, contact-based transfers, and a credit-based reward system.

---

## 🚀 Features

- 🔐 **Signup/Signin with OTP** (secure authentication)
- 📲 **Pay by Contact** (transfer to users in your contact list)
- 🧾 **Pay by UPI** (simulate UPI-based payments)
- 🔑 **Set & Verify UPI PIN**
- 🎁 **Earn credits** on each successful payment
- 💳 **Redeem credits** for discounts or cashback
- 📜 **View payment history**
- 👤 **Update user profile**
- 🚪 **Logout**

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- TypeScript
- TailwindCSS (optional)

**Backend:**
- Node.js
- Express.js
- MongoDB (with Mongoose)
- Redis (for session/OTP management)
- JWT (or any secure token for session handling)
